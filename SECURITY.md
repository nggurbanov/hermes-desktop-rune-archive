# Security

This repository covers the Electron desktop client, its preload capabilities,
local state, packaging and gateway connection handling. Agent execution and
server-side authorization belong to the connected Hermes installation.

Report a suspected vulnerability privately through this repository's GitHub
security advisories. Do not post credentials, native gateway tickets, private
conversation content or a working exploit against a live user installation in
public issues. For upstream agent issues, use the upstream Hermes repository's
security policy.
